01

Теоретичний матеріал

Ознайомся з основними поняттями створення та управління текстовими полями у бібліотеці tkinter.

📌 Віджет Entry() — Створення

Однорядкове текстове поле для введення даних від користувача створюється за допомогою класу Entry().

from tkinter import * root = Tk() entry = Entry(root, width=25) entry.pack()

📥 Метод get() — Зчитування

Метод get() повертає поточний текст з поля Entry у вигляді текстового рядка (str).

text = entry.get() print("Введено:", text)

✏️ Метод insert() — Вставка

Метод insert(index, "текст") вставляє рядок у зазначену позицію. Позиція 0 — початок поля.

entry.insert(0, "Привіт, 8 клас!")

🗑️ Метод delete() — Видалення

Метод delete(first, last) видаляє текст. Очистити все поле повністю: від index 0 до END.

entry.delete(0, END)
