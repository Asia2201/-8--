Тема 1

1. Що таке список у Python?

Список (list) — це впорядкована колекція елементів, яка може містити об'єкти будь-якого типу: числа, рядки, булеві значення або навіть інші списки.

Python
# Приклад списку покупок
shopping_list = ["яблука", "молоко", "хліб"]
print(shopping_list)
Результат виконання: ['яблука', 'молоко', 'хліб']
💡 Життєва ситуація:

Уяви свій шкільний пенал. У ньому лежать ручка, олівець, гумка та лінійка. Усе це впорядковано зберігається в одному місці — саме так працює список у програмуванні!

Тема 2

2. Створення списків

Створити список можна за допомогою квадратних дужок [ ] або функції list().

Python
empty_list = [] # Порожній список
numbers = [1, 2, 3, 4, 5] # Список чисел
mixed_data = ["Олена", 14, 10.5, True] # Змішані типи даних
Пояснення: Списки в Python універсальні — в одному списку можна зберігати ім'я (рядок), вік (число) та статус навчання (булеве значення).
Тема 3

3. Індексація елементів

Кожен елемент списку має свій номер — індекс. У Python нумерація завжди починається з 0!

"UA" Індекс: 0
"PL" Індекс: 1
"DE" Індекс: 2
Python
countries = ["UA", "PL", "DE"]
# Від'ємні індекси відраховують елементи з кінця:
print(countries[-1]) # Останній елемент "DE"
Тема 4

4. Отримання елементів списку

Щоб отримати конкретний елемент, звернися до нього за індексом у квадратних дужках.

Python
fruits = ["яблуко", "банан", "груша"]
my_favorite = fruits[1] # Беремо другий елемент (індекс 1)
print(my_favorite)
Результат: банан
Тема 5

5. Зміна елементів списку

Списки є змінними (mutable). Ти можеш присвоїти нове значення будь-якому елементу за його індексом.

Python
scores = [10, 11, 8]
scores[2] = 12 # Замінюємо 8 на 12 за індексом 2
print(scores)
Результат: [10, 11, 12]
Тема 6

6. Додавання елементів: append() та insert()

Два головні методи додавання елементів:

  • append(x) — додає елемент у кінець списку.
  • insert(i, x) — вставляє елемент x на позицію з індексом i.
Python
players = ["Олег", "Анна"]
players.append("Іван")      # ['Олег', 'Анна', 'Іван']
players.insert(0, "Марія")   # ['Марія', 'Олег', 'Анна', 'Іван']
print(players)
Тема 7

7. Видалення елементів: remove() та pop()

  • remove(значення) — видаляє перший елемент із таким значенням.
  • pop(індекс) — видаляє елемент за індексом та повертає його (якщо індекс не вказано — видаляє останній).
Python
colors = ["червоний", "зелений", "синій"]
colors.remove("зелений") # ['червоний', 'синій']
removed = colors.pop(0)    # Видалить 'червоний'
print(colors)              # ['синій']
Тема 8

8. Визначення довжини списку: len()

Вбудована функція len() повертає загальну кількість елементів у списку.

Python
items = [5, 10, 15, 20, 25]
count = len(items)
print("Кількість елементів:", count)
Результат: Кількість елементів: 5
Тема 9

9. Перебирання елементів списку за допомогою for

За допомогою циклу for можна послідовно обробити кожен елемент списку.

Python
names = ["Аня", "Максим", "Софія"]
for name in names:
    print("Привіт,", name)
Виведення:
Привіт, Аня
Привіт, Максим
Привіт, Софія
Тема 10

10. Перевірка наявності елемента за допомогою in

Оператор in дозволяє дізнатися, чи є елемент у списку (повертає True або False).

Python
menu = ["піца", "сік", "салат"]
if "піца" in menu:
    print("Піца є в меню!")
