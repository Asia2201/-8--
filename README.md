# Інтерактивний навчальний тренажер з інформатики «СПИСКИ PYTHON»

Повноцінний навчальний вебсайт українською мовою для учнів 8–9 класів, присвячений фундаментальній темі інформатики — **«Списки в Python»**.

## 🌟 Переваги та можливості проєкту

1. **Дизайн у стилі Nude / Soft Beige:** Сучасний, естетичний інтерфейс із м'якими пастельними кольорами, заокругленими картками та чудовою читабельністю.
2. **Повний теоретичний курс (10 тем):**
   - Що таке список у Python
   - Створення списків
   - Індексація елементів (додатна та від'ємна)
   - Отримання та зміна елементів
   - Додавання: `append()`, `insert()`
   - Видалення: `remove()`, `pop()`
   - Довжина списку: `len()`
   - Перебір елементів циклом `for`
   - Перевірка наявності елемента через `in`
3. **Практична робота з 15 різнорівневих питань:**
   - 1–5: Початковий рівень
   - 6–10: Середній рівень
   - 11–15: Достатній та високий рівень
   - Захист від повторного нарахування балів за один і той самий тест
   - Пояснення до кожної відповіді
4. **Персональний підсумковий звіт («Мій результат»):**
   - Поле для введення імені та прізвища учня
   - Інтерактивна кругова діаграма успішності
   - Автоматичний висновок та оцінка за 4-рівневою шкалою
   - Готовий адаптивний режим друку та збереження звіту в **PDF** через браузер
5. **100% Автономність:** Сайт працює без сервера, базі даних чи зовнішніх API. Усі дані прогресу зберігаються локально в `localStorage`.

## 🚀 Інструкція із запуску (Локально)

1. Завантажте та розпакуйте ZIP-архів.
2. Відкрийте файл `index.html` у будь-якому сучасному веббраузері (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
3. Додаткове налаштування серверного середовища (Node.js, Apache тощо) **не потрібне**.

## 🌐 Інструкція з публікації на GitHub Pages

Щоб зробити тренажер доступним онлайн для учнів:

1. Створіть новий публічний репозиторій на [GitHub](https://github.com) (наприклад, `python-lists-interactive`).
2. Завантажте всі файли з папки `python-lists-interactive` у репозиторій.
3. Перейдіть у репозиторії в **Settings** (Налаштування) -> **Pages**.
4. У розділі **Build and deployment** виберіть джерело `Deploy from a branch`.
5. У полі гілки виберіть `main` (або `master`) та папку `/ (root)`, після чого натисніть **Save**.
6. Через 1-2 хвилини ваш навчальний тренажер буде опубліковано за адресою:  
   `https://<ваш-username>.github.io/python-lists-interactive/`
